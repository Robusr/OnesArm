## Link rewrite

The original Markdown files embedded images with absolute Typora paths such as `C:\Users\LEN\AppData\Roaming\Typora\typora-user-images\image-....png`. Those paths cannot resolve on another machine. The copies here replace each embedded image with the exported checklist PNG in the same folder. The text and quantities are unchanged.

`3d_print_notes.txt` is the original `备注.txt` from the 3D-print folder; it lists quantities for the structural parts.

No mass, tolerance or surface-finish data is present in these checklists. Add it before sending parts to a shop.
