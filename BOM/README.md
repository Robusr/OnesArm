# BOM

- [`onesarm_bom.csv`](onesarm_bom.csv) — machine-readable summary, with revision and source columns.
- [`onesarm_bom.md`](onesarm_bom.md) — human-readable summary and revision-conflict warning.
- `manufacturing/` — original 3D-print, sheet-metal, carbon-tube and platform checklists, copied without modification from the project archive.
- `../electronics/output/bom/` — original PCB BOM exports (UTF-16 TSV/CSV).

The summary does **not** invent quantities where the source is ambiguous. Items marked `As required` or `As listed` need a physical fit check. No measured mass, payload or power-consumption data exists in the archive, so none is listed.
