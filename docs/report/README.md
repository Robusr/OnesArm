## Which version to cite

Use the **2025 Chinese report** for the latest design. Its Chapter 5 supersedes the v1 hardware description in Chapters 1–4. The 2024 report and deck are retained under `../archive/` for traceability.

## Evidence status

The reports contain design descriptions, FEA screenshots, MATLAB plots and qualitative conclusions. They do **not** contain measured payload, repeatability, mass or power data. See `../errata.md` and `../../data/README.md`.
