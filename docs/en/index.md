# OnesArm — Technical Documentation (English)

OnesArm is a reconfigurable modular serial robotic arm. This documentation set is the long-form companion to the repository README.

## Contents

- [Theory of Operation](theory_of_operation.md) — modular structure, FCF abstraction, 24 combinations, DH kinematics, workspace, optimisation index and statics.
- [Mechanical Design](mechanical_design.md) — links, joints, T/N mortise-and-tenon interfaces, materials, end effectors, platform and manufacturing.
- [Electronics and Control](electronics_and_control.md) — v1 Pico W servo platform, v2 STM32 CAN stepper platform, boards, interfaces and firmware status.
- [Assembly and Replication](assembly_and_replication.md) — how to choose a revision, fabricate parts, assemble, wire, run the analysis and test the prototype.
